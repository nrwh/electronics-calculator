## Divider

Markdown with TeX: `$…$` inline and `$$…$$` for display maths. It is rendered at build time.

The same current flows through both resistors, so

$$
V_\text{out} = V_\text{in}\,\frac{R_2}{R_1 + R_2}, \qquad R_2 = \frac{R_1 V_\text{out}}{V_\text{in} - V_\text{out}}.
$$

## Assumptions

- The load on the output draws no current.
